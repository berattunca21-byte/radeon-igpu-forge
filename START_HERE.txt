RULES
-----
1) Read README.md from start to end first.
2) The name torch.cuda is normal on Radeon; this install is ROCm/HIP, not CUDA.
3) If torch.cuda.is_available() is False, do not silently fall back to CPU — fix the environment (README Sec.9).
4) The system "python" has no GPU. For training use ONLY:
     GPU_PYTHON.cmd script.py        (recommended — also sets the env vars)
   or the full path:
     <PROJECT>\venv-rocm10\Scripts\python.exe
   + env: PYTORCH_TUNABLEOP_ENABLED=1  PYTORCH_TUNABLEOP_HIPBLASLT_ENABLED=0
          PYTORCH_TUNABLEOP_MAX_TUNING_DURATION_MS=200
   (Backup: <OLD_VENV_THEROCK> — torch 2.12)
5) FASTEST MEASURED PATH (~1.40M samples/s, 3.1x FP32):
   pure fp16 + fp32 master weights + TunableOp(rocBLAS) + fused HIP L1. Health check:
     GPU_PYTHON.cmd ml\bench\bench7_fused_e2e.py    -> ~1.39-1.44M, err=0.0000
   In your own model: from fxgpu import WindowMLP  (README Sec.7)
     GPU_PYTHON.cmd ml\fxgpu\train_template.py --npz DATA.npz
6) Training rules: NO DataLoader (GPU indexing), NO Conv1d (wflat), batch 8192-32768
   (8192-16384 for small data — README Sec.7), NO loss.item() inside the batch loop, tensors on the GPU from the start,
   pure fp16 (NOT autocast) + fp32 master weights (pure fp16 AdamW diverges — measured),
   isfinite check, weight_decay instead of dropout. F (feature count) % 8 == 0.
7) HARDWARE (27 Sep 2026): DUAL CHANNEL ACTIVE — 2x16 GB DDR5-5600 (running at 4800 MT/s; Hynix
   Channel A + Micron Channel B, both slots populated, ~27.7 GB visible). The old "single channel ~38 GB/s"
   bottleneck is gone; earlier speed measurements (including 1.40M samples/s) were taken on single channel,
   the dual-channel gain is to be confirmed in the first bench7 run. Plugged in + "Ultimate Performance".
8) PACKAGE INDEX CHANGED: rocm.nightlies.amd.com/whl-multi-arch is NOW LEGACY (frozen at 20260822).
   New: stable.repo.amd.com/rocm/whl-next (ROCm 10.0.0 STABLE, gfx1035 Windows available)
   and nightly.repo.amd.com/rocm/whl-next (10.2 nightly). If the environment breaks, offline install:
   ml\README.txt (wheels-rocm10; --pre is required because networkx is an rc).
9) Only ONE GPU process at a time (the iGPU is shared; a second process ruins speed and measurements).
10) Every GPU run writes tunableop_results0.csv to the working directory — harmless, can be deleted.
11) Do not run long/unbounded GPU experiments: small shape first + timeout + write output to a file (the PC froze once on 24 Sep 2026).

Measurement summary (500k x 40, wflat W=30, bs=32768, re-measured 20 Sep 2026):
  FP32 ~455k -> pure fp16 ~920k -> +TunableOp ~1.30M -> +fused HIP L1 ~1.40-1.44M samples/s
  fp32 master weights: -1% speed, no divergence.  2M-param model: ~268k/s (~1.84 s/epoch).
  Language model (fxlm, 24 Sep 2026): 1.9-2.7x over a naive PyTorch GPT (T256-T1024), 2.07x on a 600-step training run, same quality — README Sec.12.
